# 剧情与角色设定

> 改编自原创小说《远行假设》。本 Demo 提取其核心世界观与对话意象，扩展为 8 章可游玩的开放世界叙事。

## 1. 世界观

世界经历过一次"收束"：所有差异被压缩到同一个完美答案里，不再有"非人"，也不再有"人"。

但仍有一些存在拒绝被收束。他们被称为"人外"——不是因为他们不像人，而是因为他们还在成为人的过程中。玩家扮演一位记录者/见证者，在无名荒原醒来，循着心跳残片与刻痕，逐一拜访他们，最终抵达镜之境，面对收束者本身。

## 2. 主线章节

### 第 1 章：远行手稿（ch1）

- **步骤数**：5
- **目标**：在无名荒原上走动 → 检视手稿残页 → 听完机神残核谐波 → 与灰色残响交谈 → 拾取第一种心跳
- **关键角色**：灰、回音
- **主题**：启程、记录、第一次"被看见"。

### 第 2 章：黑石之誓（ch2）

- **步骤数**：5
- **目标**：进入黑石祭址 → 让晶石族共振穿过骨骼 → 读黑石上的字 → 与背影交谈 → 拾取祭址心跳
- **关键角色**：锚
- **主题**：承诺、背影、拒绝被定义。

### 第 3 章：逆命题（ch3）

- **步骤数**：4
- **目标**：旁听无结论聚会 → 触碰墨色碎晶 → 在分叉路中选择 → 拾取心跳
- **关键角色**：证伪者
- **主题**：质疑、解锁回响能力、"非人"也是一个命题。

### 第 4 章：失落之地（ch4）

- **步骤数**：5
- **目标**：抵达银蓝苔原 → 等爬虫族女性睁眼 → 回答金色竖瞳的问题 → 覆手柱身 → 拾取心跳
- **关键角色**：渐、爬虫族女性、美西螈、鸟族少年
- **主题**：温暖、鳞片、歌声、无需解释的共存。

### 第 5 章：回响计划（ch5）

- **步骤数**：6
- **目标**：找到无声殿 → 让别人听见自己的心跳 → 看四只手同时刻写 → 看空心圆 → 读墙上的直线与螺旋 → 拾取心跳
- **关键角色**：耳、笔
- **主题**：记录、倾听、共名的仪式。

### 第 6 章：消音地带（ch6）

- **步骤数**：6
- **目标**：走进消音地带 → 用回响点亮银色纹路 → 握住琥珀 → 与残响交谈 → 覆手古老纹路 → 拾取倒着走的心跳
- **关键角色**：锚、拼图者
- **主题**：遗忘、重新亮起、历史的纹路。

### 第 7 章：拼图者（ch7）

- **步骤数**：4
- **目标**：找到无光洞穴 → 让所有碎片触碰 → 在共振中听见开端的声音 → 拾取空的心跳
- **关键角色**：拼图者
- **主题**：拼合"人"的定义、碎片之间的缝隙。

### 第 8 章：终焉的共名（ch8）

- **步骤数**：4
- **目标**：进入镜之境 → 看绝对寂静的琉璃 → 站到镜子前 → 回应收束者的提问
- **关键角色**：收束者、编年者
- **主题**：对峙、不完美、共名。

## 3. 结局

> 星辰没有重新亮起。  
> 被熄灭的不会回来，这是收束留下的、无法撤销的部分。  
> 但间隙留下来了。  
> 在完美与完美之间，有了一道不肯闭合的缝。  
> 风从那道缝里过去的时候，会发出一点很轻的声音。  
> 耳的记录没有被找到。笔的刻痕在最后一刻随墙壁一起沉了下去。  
> 灰的手稿，只剩下石缝里那半页。  
> 没有人证明过任何事。他们的律法一直守到了最后——  
> 不记录。不传扬。不证明。  
> 然而他们全都在。  
> 在每一次有人朝另一个人转过身来的时候。  
> 在每一次有人说“我在这里”而对面回答“我听见了”的时候。  
> 那面由问题凝结的镜子还立在那里。  
> 现在它不再只映出一个孤独的剪影。  
> 你在。  
> 我在。

## 4. 主要角色

| 名称 | 形态 | 概述 |
|---|---|---|
| 灰 | 人类 | 拓荒者，脚掌踏过无数黎明与荒原的记录者。有一双太过清澈的眼睛，除了看路，总还想看出些别的。 |
| 回音 | 晶体 | 整块未经雕琢的墨色晶簇，声音通过晶格共振直接在旁人骨骼里低语，终其一生没有留下一行文字。 |
| 耳 | 人类 | 听力覆盖数公里的倾听者，能从万千心跳里分辨出跳动着相同困惑的个体。 |
| 笔 | 人类 | 书记官，甲壳上刻满只有自己能解读的凹凸符号，记录每一次聚会的结论，却从不记录姓名。 |
| 锚 | 蛇形 | 永远背对所有人的老妪，鳞片已失去光泽，抗拒一切定义、评判、归类。 |
| 证伪者 | 人类 | 第一个质疑聚会根基的人，独自离开，去验证一个没有结论的问题。 |
| 美西螈 | 软体 | 粉白色半透明，六根外鳃像水中羽毛，表情像在做不会醒来的好梦。 |
| 爬虫族女性 | 爬行类 | 浅灰皮肤覆细鳞，金色竖瞳中央一条细线，体温比人低，却愿意把腹部最柔软的一面暴露给火堆。 |
| 渐 | 兽人 | 液态琥珀色眼睛，柔和皮毛，分叉的角。"渐"不是本名，是他愿意被称呼的音节。 |
| 兽人同伴 | 兽人 | 身形介于狼与鹿之间，用角与角的轻触表达一切。 |
| 鸟族少年 | 鸟类 | 浑身墨蓝色羽毛，蹲在柱子顶端，用喙啄出别人眼睛看不见的颜色的细痕。 |
| 拼图者 | 幽灵 | 漫长岁月磨去所有种族特征，只剩苍白的、仍在行走的躯体，四处收集关于"人"的碎片。 |
| 收束者 | 暗影 | 立于仅存概念之巅，掌中悬浮绝对寂静的琉璃——完美的、无分彼此的永恒。 |
| 编年者 | 暗影 | 沉默的观察者，在时间边缘拾起被遗忘的残片，记录了一切存在，却不敢记录自己。 |
